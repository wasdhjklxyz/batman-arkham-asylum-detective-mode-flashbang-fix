Arkham Asylum Flashbang Fix

Stops the blinding white flash every time you toggle detective mode in Batman: Arkham Asylum. Nothing else changes.

Your file is never uploaded. It is patched right here in your browser, then handed back to you as a download.

1. Find your BmGame.u

  1. In Steam, right-click Batman: Arkham Asylum GOTY Edition → Manage → Browse local files.
  2. Open BmGame, then CookedPC.
  3. Find BmGame.u (about 60 MB).

Usually C:\Program Files (x86)\Steam\steamapps\common\Batman Arkham Asylum GOTY\BmGame\CookedPC\BmGame.u

2. Drop it here

3. Put it in the game

Download fixed BmGame.u

  1. Close the game if it's running.
  2. In CookedPC, rename your current BmGame.u to BmGame.u.bak. That's your backup.
  3. Move the downloaded BmGame.u into CookedPC. If your browser named it BmGame (1).u, rename it to exactly BmGame.u.
  4. Play. No more flashbang.

The new file is bigger (about 100 MB). That's expected, it's stored uncompressed now.

Undo

Delete the fixed BmGame.u and rename BmGame.u.bak back to BmGame.u. Or in Steam: Properties → Installed Files → Verify integrity of game files. Heads up, verifying also undoes the fix if you run it later.
